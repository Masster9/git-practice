# git-practice

Практическое задание по Git (курс РКИС, занятие 1).
Выполнил: Киснер Артём, группа 3831.

В репозитории отработаны команды Git: init, add, commit, status, log, diff, branch, checkout, merge, remote, push, pull.
Файл .gitignore исключает из репозитория логи и папку temp.
В ветке feature изменения сливались в master сначала fast-forward, затем с разрешением конфликта.
